# 📊 Zoom Meeting & Recording Live Tracker

A real-time Zoom meeting tracking dashboard with participant analytics, health metrics, recording summaries, and more.

## Features

- **Live Dashboard** — Real-time stats, charts (daily activity, health distribution, top participants, hourly trends)
- **All Meetings** — Search & filter all meetings with complete details
- **Participants** — Full directory with engagement metrics per person
- **Recordings** — AI-generated meeting summaries with health scores
- **Meeting Detail** — Participant join/leave timeline, conversation gaps, health breakdown

## Deploy to Vercel

### Option 1: Vercel CLI (Recommended)

```bash
# Install Vercel CLI
npm install -g vercel

# Navigate to project folder
cd zoom-tracker-vercel

# Deploy
vercel

# For production deployment
vercel --prod
```

### Option 2: GitHub + Vercel Dashboard

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) and sign in
3. Click "New Project" → Import your GitHub repo
4. Framework Preset: **Vite**
5. Click "Deploy"

### Option 3: Drag & Drop

1. Run `npm run build` locally
2. Go to [vercel.com](https://vercel.com)
3. Drag the `dist` folder to deploy (Note: API functions need CLI or GitHub deploy)

## Tech Stack

- **Frontend**: React 18 + Recharts + Vite
- **Backend**: Vercel Serverless Functions (Node.js)
- **Data**: Pre-loaded Zoom meeting data (250 meetings)
